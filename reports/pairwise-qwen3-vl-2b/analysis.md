# Qwen3-VL-2B 成对重量比较微调

按 dev accuracy、再按较低 MSE 选择 full 的第 3 个 epoch（第 3000 步）。默认模型在 dev 上超过零样本 Qwen（54.4%）和体积规则（82.1%），本轮停止调参，保留单 seed 的结果。

## 训练与复现

- 本地 main 提交 `981b8bf`。模型 `Qwen/Qwen3-VL-2B-Instruct`，revision `89644892e4d85e24eaac8bacfd4f463576704203`。RTX 4090，CUDA BF16，SDPA。源码安装的 PEFT 0.17.1。固定 revision 的模型从项目内缓存加载。
- 每轮 8,000 个训练对，1,000 个 dev 对。每个模型训练 3 轮，每轮 1,000 次更新。microbatch 1，梯度累积 8，seed 42，图像上限 262,144 像素。
- 训练参数 3,211,264/2,130,743,296。LoRA 仅更新语言注意力 q/k/v/o，rank 8、alpha 16、dropout 0.05。冻结视觉编码器和基础权重。AdamW，初始设置 LR 1e-4，weight decay 0.01，3% warmup 后线性衰减，梯度裁剪 1.0，启用梯度 checkpointing。
- 模型读取两幅图及尺寸。在首个答案位置对 A/B logits 归一化，以 A 的概率对二元标签计算 MSE。

## 是否调整训练

建议保留默认配置和第 3 轮 checkpoint 作为本次结果。三轮 dev 准确率持续上升，dev MSE 持续下降。预定义的 179 对体积规则失误样本上，各轮分别答对 86、94、100 对（48.0%、52.5%、55.9%）。按完整 dev 和困难 dev 衡量，第 3 轮均为已测最佳。现有结果只覆盖 seed 42，无法估计随机种子间的波动，也无法判定继续增加 epoch 是否会改善。

完整 test 的 119 个错误中，82 个集中在 168 对困难样本中（占全部错误的 68.9%）。相对零样本基准，模型在困难子集纠正 51 对，同时新增 39 个错误，净增 12 对。完整 test 上净增的 342 对中有 330 对来自体积规则正确的样本。397 个纠正发生在正确答案为 A 的样本上，表明收益很大一部分来自缓解零样本模型偏选 B 的现象。

如果后续目标专门看重困难样本，可只用训练集构造体积规则出错的训练对，提高其采样比例，并在 dev 上同时比较总体准确率和困难子集准确率。当前 test 已用于最终评估，后续配置选择应继续使用 dev。报告中的完整训练耗时仅计成功完成的运行，先前中断的 57 步及两次运行之间的空档另计。
